# Contact Book App

## Run
```bash
python main.py
```

## Features
- Add, view, update, and delete contacts (CRUD).
- Search by name, phone, email, or address.
- Alphabetical sorting by contact name.
- Data is stored persistently in `contacts.json`.
- Basic name, phone, and email validation.

## Concepts used
Tkinter, JSON file handling, lists, dictionaries, sorting, searching, and exception handling.

`contacts.json` is created automatically when the first contact is saved.
