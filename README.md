# Snake & Ladder Game

## Run
```bash
python main.py
```

## Features
- Two-player turn-based game.
- Random dice rolls from 1 to 6.
- Snakes move a player backward; ladders move a player forward.
- Players must roll the exact number to reach square 100.
- Live 10 x 10 board, winner announcement, and New Game button.

## Concepts used
Tkinter GUI, classes, lists, dictionaries, functions, conditionals, loops, and `random.randint()`.
