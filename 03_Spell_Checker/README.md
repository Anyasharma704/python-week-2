# Spell Checker App

## Run
```bash
python main.py
```

## Features
- Accepts a text passage from the user.
- Finds words not present in a built-in starter vocabulary.
- Suggests up to three close matches using Levenshtein edit distance.
- Displays possible spelling mistakes in a results area.

## Concepts used
Tkinter, regular expressions, sets, loops, sorting, and the Levenshtein distance algorithm.

## Note
This is an educational spell checker with a small built-in vocabulary, not a complete English dictionary. You can expand the `WORDS` set in `main.py` for better coverage.
