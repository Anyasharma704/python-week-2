# Student Grade Management System

## Run
```bash
python main.py
```

## Features
- Add, view, update, and delete student records.
- Store roll number, student name, and marks in multiple subjects.
- Automatically calculate average marks and assign a grade.
- Search by roll number or student name.
- Sort student records alphabetically by name.
- Save records persistently in `students.json`.
- Validate required fields, duplicate roll numbers, and marks from 0 to 100.

## Grade scale
- 90–100: A+
- 80–89.99: A
- 70–79.99: B
- 60–69.99: C
- 50–59.99: D
- Below 50: F

## Concepts used
Tkinter, JSON file handling, lists, dictionaries, functions, validation, sorting, and exception handling.
